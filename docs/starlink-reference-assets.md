# Starlink animation reference assets
Retrieved 2026-09-11. NASA maps are included under public/textures/starlink. Official Starlink photographs remain modeling references only.

## Earth maps (usable texture assets)

- earth-day-nasa-5400.jpg: 5400 x 2700 JPEG, NASA Blue Marble Next Generation, July 2004, topography and bathymetry. Visually inspected: complete 2:1 equirectangular longitude/latitude map, north up, all continents, antimeridian seam at left/right. This is the downloaded source resolution; no 2K/4K derivative was made.
  Source: https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/
  Image: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-topography-bathymetry/july/world.topo.bathy.200407.3x5400x2700.jpg
  Credit: NASA Earth Observatory / Blue Marble Next Generation.
- earth-clouds-nasa-2048.jpg: 2048 x 1024 JPEG, RGB grayscale cloud mask, visually inspected. Black clear sky, white clouds; use as an alphaMap or derive opacity from luminance. The file itself has no alpha channel. Complete equirectangular global cloud composite.
  Source: https://visibleearth.nasa.gov/images/57747/blue-marble-clouds/77558l (legacy page now redirects; indexed archive identifies this asset).
  Image: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57747/cloud_combined_2048.jpg
  Credit: NASA Goddard Space Flight Center, image by Reto Stockli.
- earth-night-nasa-3600.jpg: 3600 x 1800 JPEG, 2016 Black Marble global night lights.
  Source: https://science.nasa.gov/earth/earth-observatory/earth-at-night/maps/
  Image: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/imagerecords/144000/144898/BlackMarble_2016_01deg.jpg
  Credit: NASA Earth Observatory images by Joshua Stevens, using Suomi NPP VIIRS data from Miguel Roman, NASA GSFC.

  Antenna dimensions: 594 x 383 x 39.7 mm. Electronic phased array, 110 degree field of view, software-assisted manual orientation. Weight 2.9 kg, 3.2 kg with kickstand. Typical power 75-100 W.

For faithful visual modeling: thin flat satellite chassis with two opposing rectangular solar wings, white panel face and dark perimeter hardware; terminal is a thin rectangular panel with kickstand, no pole/motor base.
