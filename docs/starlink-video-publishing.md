## Audio and edit workflow
The downloadable visual masters contain the brand, brief chapter titles and technical labels, with no narration captions. Record the two scripts separately. Use the timecoded narration sheets and JSON cues, align each paragraph to its chapter, and leave about 0.4 seconds at the end of each cue. Import the assembled MP3 or WAV through the lab's Add voiceover control to include it in a new recording, or mix it with the master in Shotcut.

The lab is local on a feature branch until reviewed and deployed. Verify the public /starlink page is live before publishing either description.
